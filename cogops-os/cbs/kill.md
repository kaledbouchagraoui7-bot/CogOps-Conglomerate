# CBS Ch.6 — Kill & Wind-down (OS §5, I8)
1. Kill requires an evidence pack (reason + data) — no vibes kills; kill is recorded as **KILL_WIN** and credits the squad (+10% cap, max +50%).
2. Wind-down order: client continuity first (deliverables handed off / refunded per contract), then data export for the owner, then asset return to platform pool (domain, KB, templates), then ledger closure.
3. A portfolio that never kills is failing the funnel — kill-rate is reviewed quarterly.
