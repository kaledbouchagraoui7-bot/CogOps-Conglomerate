# CogOps Group — The Central Business (the holding, as code + skin)

> The holding is not a company that sells. It is the machine that makes companies, the skin they wear, and the spine they share. Live face: https://cogops-group.pages.dev (+ /governance.html). Doctrine: OS §2 + §16, DR-0004/0011/0012.

## What the holding owns — and all it owns
1. **The gate** — every Type-1 action in every company ends at one founder keystroke (`gates.py`, phone-push via `notify.py`).
2. **The capital ladder** — fortress first, then reinvest/launch/sweep/acquire (`capital.py`); FCF-per-company-month is the only scoreboard.
3. **The brand** — `cogops-os/data/theme.json` is the single source; `holding.brand_lockups()` generates the group mark + ten endorsement lockups into `../brand/`. **Nobody hand-edits brand SVGs**; theme changes are DRs.
4. **The playbook** — CBS (`cogops-os/cbs/` chapters, versioned by content hash); amendments via DR only.
5. **The platform** — site factory, LLM gateway with caps, CRM patterns, catalog (`platformsvc`), pull-only by construction.
6. **The nervous system** — senses/reflexes/pain/nerves/consciousness (`nervous.py`, `dashboard.py`); the public site publishes what the body feels only as facts (invariants, stages, graph), never the private consciousness.

## Commands (the holding's console)
```
python3 cogops.py group brand         # regenerate the clothes (11 lockups, deterministic)
python3 cogops.py group invariants    # I1-I12, executable, with proof method each
python3 cogops.py group status        # allocator's view: stages, P&Ls, envelopes, URLs, promises, boundaries
python3 cogops.py group build         # rebuild group/site/public/{index,governance}.html from LIVE state
python3 cogops.py dashboard [--serve] # the private consciousness (localhost only)
```
Rebuild + redeploy the group site after any structural change (new company, new edge, new DR): `group build` → `wrangler pages deploy public --project-name=cogops-group`.

## Honesty rules of the skin
- The public invariants table is **generated by code** (`holding.invariants()`) — it cannot be edited into looking better; a FAIL publishes itself.
- The trade graph on the index is the **live LINKS registries**, not a diagram someone drew.
- Counts/quotes carry as-of timestamps; the group admits "entity in formation" on every legal page until the GmbH exists (DR-0004).
- The stakeholder door routes to a human within 1 business day; nothing auto-replies (inbox doctrine, group-wide).
