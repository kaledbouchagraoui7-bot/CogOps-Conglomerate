Doctrine in one breath

How one human governs ten companies

The gate

Type-1 (external/financial/irreversible) actions stage with an evidence pack and wait for a keystroke — pushed to the founder's phone on staging. Type-2 runs free inside envelopes. Nothing self-approves; the inbox has no send() function at all.

The pain

Critical signals (broken ledger chain, fortress breach) freeze group spending automatically. Integrity freezes release only via the founder's confirmation phrase. The machine stops; it does not limp.

The nerves

Every trade edge is a dependency nerve: if a seller degrades, every buyer's evidence chain is flagged automatically. Pairs, clique and star are derived from code registries, not diagrams.

The consciousness

The founder dashboard (localhost-only) renders the body: organ map, vitals, gate queue, signal feed, missions. Public transparency stops at this page by design — the consciousness is private, the facts are public.
